# Beats - Music Player



## Features

- ⏯️ **Play & Pause** – Start and stop music playback.
- ⏩ **Skip Forward & Backward** – Navigate between tracks.
- 🔊 **Volume Control** – Adjust the sound level.
- 🌐 **Cross-Platform** – Works on web and mobile.

## Tech Stack

- **Frontend:** HTML,CSS ,TailwindCSS 
- **Backend:** NODE JS
- **Audio Streaming:** Web Audio API



## Future Enhancements
